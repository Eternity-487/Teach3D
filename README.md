# BikeLab 3D：Trek Marlin 6 机械工程交互教学模型

面向机械专业课程教学的山地自行车三维可视化项目。模型以 Trek 2023 款 Marlin 6 为参考，可在浏览器中旋转、缩放和查看关键机械结构，适合课堂投屏、结构讲解与课后演示。

## 在线课堂演示

[打开最大化交互模型](https://trek-marlin-6-mechanical-teaching.qitan874.chatgpt.site)

建议使用电脑浏览器并进入全屏模式，以获得更好的课堂展示效果。

## 教学内容

- 三维整车自由旋转、缩放与视角复位
- 车架、传动、制动、转向、悬架和轮组结构展示
- 机械专业风格的部件标注与参数说明
- 适合结构组成、工作原理和设计分析课程

## 本地使用

```bash
npm install
npm run dev
```

也可以直接打开 `public/trek-marlin-6-teaching-3d.html` 查看独立版本。
